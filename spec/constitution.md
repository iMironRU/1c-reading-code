# Конституция книги

## Что эта книга ЕСТЬ

- Учебный курс чтения кода 1С для абсолютных новичков без опыта программирования
- Рассматривает 1С как **язык описания и преобразования данных в деловой системе** — не как набор синтаксических конструкций
- Несущий приём — метафора иностранного языка: лексика → семантика → структура → идиомы → контекст
- Медленный вход (Модули 0–2), ускорение к концу
- Каждый параграф — один концептуальный сдвиг, не просто термин

## Что эта книга НЕ ЕСТЬ

- Не справочник по синтаксису 1С
- Не курс по конфигурированию или администрированию
- Не «быстрый старт» — намеренно медленная на входе
- Не для людей с опытом программирования (им скучно в начале)
- Не IT-блог с плакатными блоками и эмодзи

## Метафора книги

Изучение 1С как иностранного языка: сначала буквы и слова (лексика), потом смысл (семантика), потом грамматика (структура), потом устойчивые обороты (идиомы), потом погружение в живой текст (контекст).

## Принципы изложения

1. **Объяснять не только что, но и почему так вообще можно** — нельзя опираться на интуицию из других языков
2. **Никаких абсолютов** — «возникает когда…», «требует…» вместо «без X нет Y»
3. **Никакого антропоцентризма** — правило формулируется для программы, а не для человека
4. **Метафора всегда с парной строгой формулировкой** — бытовой образ + точное определение
5. **Одна новая ось сложности на параграф** — после плотного параграфа следующий легче

## Что автор не будет делать никогда

- Вводить понятие и нигде не использовать его в том же параграфе
- Предполагать знание других языков программирования
- Дробить связные объяснения на маркированные списки без необходимости
- Использовать эмодзи в основном тексте

## Аудитория (кратко)

Читатель: бухгалтер, менеджер, аналитик — человек, который работает в 1С и хочет понимать код, который видит; без опыта программирования.

Читатель НЕ: разработчик с опытом в другом языке, человек, которому нужна быстрая шпаргалка.
