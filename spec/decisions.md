## [2026-06-08] Переход на book-template

**Проблема:** книга разошлась со стандартом шаблона — разные схемы metadata.yaml, нет статусов глав, MkDocs вместо mdBook.

**Решение:** мигрировать на book-template v0.1.0: mdBook, frontmatter status, единый book.sh.

**Почему:** стандартизация упрощает поддержку, автоматическая сборка через GitHub Actions, совместимость с другими книгами серии.

**Альтернативы:** оставить MkDocs (работал, но расходился с шаблоном серии).

## [до 2026-06-08] Метафора иностранного языка как несущий приём

**Проблема:** нужно объяснить структуру курса новичку без программирования.

**Решение:** метафора «1С как иностранный язык» — лексика → семантика → структура → идиомы → контекст.

**Почему:** знакома всем без исключения, задаёт порядок изучения без лишних объяснений.

## [до 2026-06-08] Сквозной пример — фирма «Канцтовары»

**Проблема:** нужен сквозной пример понятный читателю без знания предметной области.

**Решение:** торговая компания «Канцтовары» — канцелярия, склад, поставщики, покупатели.

**Почему:** знакома всем, не требует объяснения, покрывает типовые операции 1С.

**Альтернативы:** производственное предприятие (слишком сложно), услуги (нет склада, не показывает ТМЦ).

## [до 2026-06-08] Устоявшиеся терминологические решения

Зафиксированы в тексте, должны соблюдаться во всех последующих параграфах:

- **Коллекция** — это *значение* особого рода, способное хранить внутри несколько других значений. Не «переменная, которая хранит несколько значений».
- **Переменная цикла** в «Для каждого Из» — одна и та же переменная на всех итерациях.
- **Итерация** — один полный проход через тело цикла (введено в § 3.2).

## [до 2026-06-08] Заголовки параграфов: `§ N.M. Название`

**Решение:** заголовок параграфа содержит номер в формате `§ N.M.` — для навигации и перекрёстных ссылок.

**Почему:** читатель легко находит параграф по номеру в оглавлении и в тексте («вернёмся к этому в § 3.2»).
