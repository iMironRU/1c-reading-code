## О книге

Главная идея — рассматривать 1С как **язык описания и преобразования данных в деловой системе**, а не как набор синтаксических конструкций.

Метафора иностранного языка проходит через весь курс: лексика → семантика → структура → идиомы → контекст. Сквозной пример — фирма «Канцтовары».

**Для кого:** бухгалтер, менеджер, аналитик — человек, который работает в 1С и хочет понимать код, который видит. Без опыта программирования. Не для разработчиков из других языков.

### Структура репозитория

```
chapters/          — параграфы (NN_модуль/NN-MM_параграф.md)
assets/img/        — обложка и иллюстрации
spec/              — конституция, спецификация, журнал решений
docs/              — план курса, рабочие заметки
scripts/           — рецензирование через AI API
```

### Собрать локально

Требования: `pandoc`, `python3` + `pyyaml`, `mdbook`.

```bash
./book.sh build        # все форматы
./book.sh build ready  # только финальные главы
./book.sh status       # прогресс по параграфам
```

### Сборка на GitHub

При создании тега `v*` GitHub Actions автоматически собирает все форматы и публикует Release. Ночные сборки (Pre-release) создаются ежедневно при наличии новых коммитов.
