## § 5.1. Объекты, свойства и методы

**К упражнению 1.** *Полное решение.*

```bsl,песочница
Список = Новый СписокЗначений;  // создание объекта
Список.Добавить("Ручка");       // вызов метода-процедуры
Список.Добавить("Карандаш");    // вызов метода-процедуры
Н = Список.Количество();        // вызов метода-функции; результат в переменную
Сообщить("Позиций: " + Н);      // глобальная функция Сообщить
Д = СтрДлина("Карандаш");       // глобальная функция СтрДлина
Сообщить(Д);                    // глобальная функция Сообщить
```

`СтрДлина` — глобальная функция, а не метод: перед ней нет объекта и точки.

## § 5.3. Табличные части: коллекция строк внутри документа

**К упражнению 1.** *Полное решение.*

Программа считает, сколько строк в табличной части `Товары` имеют ненулевое количество (больше 0). Это паттерн агрегации — счётчик с условием (§ 4.4).

## § 5.4. Что такое ссылка и зачем она нужна

**К упражнению 1.** *Полное решение.*

Три объекта в цепочке:
1. `Документ` — сам документ.
2. `Документ.Склад` — реквизит документа, ссылка на склад (элемент справочника «Склады»).
3. `Документ.Склад.Ответственный` — реквизит склада, ссылка на сотрудника (элемент справочника «Сотрудники» или «Физические лица»).
4. `Документ.Склад.Ответственный.Наименование` — строковый реквизит сотрудника.

Цепочка читается: «у документа возьми склад, у склада возьми ответственного, у ответственного возьми наименование».

## § 5.5. Типичные обороты реального кода

**К упражнению 1.** *Полное решение.*

(а) Сторожевая проверка: если реквизит `Контрагент` у документа не заполнен (пустая ссылка) — выйти из подпрограммы. Это защитный код перед работой с контрагентом.

(б) Получить объект по ссылке, изменить реквизит `Статус`, сохранить изменения в базу.

(в) Перебрать все элементы справочника «Склады» и вывести наименование каждого. Паттерн перебора, применённый к выборке из базы.

## § 5.6. Первое чтение фрагмента из настоящей конфигурации

**К упражнению 1.** *Полное решение.*

Паттерны: **защитный код** (сторожевая проверка параметра) + **перебор с фильтрацией** (пропуск товаров других поставщиков) + внутри — цикл «получить → изменить → записать».

Идиомы: `ЗначениеЗаполнено()`, `Выбрать()`, `Пока Выборка.Следующий()`, `Выборка.Ссылка.ПолучитьОбъект()`, `.Записать()`.

Процедура принимает ссылку на поставщика и процент изменения цены. Перебирает весь справочник Номенклатура, пропуская товары, принадлежащие другим поставщикам. Для товаров указанного поставщика увеличивает цену на заданный процент и сохраняет изменения.
