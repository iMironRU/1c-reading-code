# 1С как иностранный язык

> Учебный курс для абсолютных новичков без опыта программирования.

---

## Главная идея

Рассматривать 1С не как набор синтаксических конструкций, а как **язык описания и преобразования данных в деловой системе**.

Метафора иностранного языка проходит через весь курс:

```
слова → семантика → синтаксис → фразеологизмы → стиль → контекст → дискурс
```

Через все параграфы проходит сквозной сюжет — фирма **«Канцтовары»**: три сотрудника, десяток товаров, пара клиентов, простая бухгалтерия.

---

## Что даёт курс

После прохождения курса читатель умеет:

- **читать** код 1С как осмысленный текст, а не как шифр
- **понимать** — что делает программа и зачем она так устроена
- **оценивать** качество кода: правильность, обработку ошибок, производительность
- **ориентироваться** в конфигурации: находить нужный модуль, идти по цепочке вызовов
- **продолжать** изучение платформы самостоятельно

## Как читать

Каждый параграф устроен одинаково:

1. **Открытие** — связь с предыдущим, новый вопрос.
2. **Содержательные разделы** — объяснение с примерами на коде 1С.
3. **Главное в одном абзаце** — сжатый итог.
4. **Контрольные вопросы** — самопроверка.
5. **Упражнения** — практика с ответами.
6. **Мостик** — переход к следующему параграфу.
